# LinnoChat widget demo site

A fictional municipality website for trying the LinnoChat chat widget on a real page.
The municipality and its content are made up.

- **English page** (`/en/`): a fictional city council site with the Staging "Recycling habits" widget (English).
- **Hebrew page** (`/`): a fictional municipality with the Staging Muni Forms demo widget.
- **Your own widget:** open "Test tools" / "כלי בדיקה" (top left), paste the embed snippet from
  Configuration → WebChat → Widget, and click "Show on site".
- **By link:** `?survey=<project id>` (Staging, account `convercx`), or add `&env=dev` and `&account=<id>`.

Conversations started here are saved as Live, because this is not a test domain.
